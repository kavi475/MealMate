# 🍽️ MealMate - Smart College Canteen Ordering System

A full-stack MERN application for campus canteen ordering.

## ✨ Features

### User Features

- 🔐 Authentication (Register/Login/Logout)
- 🍽️ Browse menu with search & filters
- 🛒 Real-time cart (persists in database)
- 💳 Checkout with delivery address
- 📦 Order placement & tracking
- 👤 Profile management
- 🔒 Password change
- ❤️ Favorites system

### Admin Features

- 📊 Dashboard with real-time stats
- 🍽️ Menu management (CRUD)
- 📦 Order management & status updates
- 👥 User management
- 📈 Reports & analytics with charts

## 🛠️ Tech Stack

**Frontend:**

- React.js + Vite
- React Router DOM
- Context API
- Axios
- Pure CSS

**Backend:**

- Node.js + Express.js
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs
